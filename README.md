# Paradise Nursery

## Project Name

Paradise Nursery

## Project Description

Paradise Nursery is a shopping application for a plant nursery. The application allows users to browse a collection of houseplants, view plant information, and add plants to a shopping cart.

## Features

* Landing page for Paradise Nursery
* Browse houseplants by category
* Display plant images, names, and prices
* Add plants to the shopping cart
* Dynamic shopping cart item count
* Increase and decrease plant quantities
* Remove plants from the cart
* Display individual plant costs
* Display total cart amount
* Continue shopping
* Checkout option
* About Us page

## Technologies Used

* React
* JavaScript
* Redux Toolkit
* HTML
* CSS
* Vite
